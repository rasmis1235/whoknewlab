Who Knew Lab pipeline

Privacy Policy

Effective date: 10 November 2026

This policy covers the Who Knew Lab pipeline ("the tool"), a private software tool used only by the owner of the Who Knew Lab YouTube channel to publish videos to, and read analytics from, that one channel.

YouTube API Services

The tool uses YouTube API Services (YouTube Data API v3 and YouTube Analytics API). Anyone using the tool agrees to the YouTube Terms of Service. Data accessed through YouTube API Services is also subject to the Google Privacy Policy.

Who uses the tool

Only the channel owner. The tool is not public, has no sign-up, and no other person's Google account is ever connected to it.

What data the tool accesses

  • The owner's own channel: channel name, handle and the list and status of the owner's own videos (via OAuth scopes youtube.readonly).
  • Uploads: the owner's own video files, titles, descriptions, tags and thumbnails, sent to YouTube (scope youtube.upload).
  • Analytics for the owner's own channel: views, watch time, average view percentage, likes, comments, subscribers gained, shares and audience-retention curves (scope yt-analytics.readonly).

The tool does not access, collect or store any data about viewers, other channels or other users. It does not use cookies, tracking, advertising identifiers or third-party analytics.

How the data is used

Only to upload and schedule the owner's videos and to compare the performance of the owner's own videos so the next video can be improved. Data is never sold, shared, transferred or disclosed to any third party.

Storage and retention

  • The OAuth token is stored only on the owner's own computer, in a local file that is never uploaded or shared.
  • Analytics results are kept as small summary files on the owner's own computer. Data retrieved through the YouTube API is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
  • No data is stored on any server or cloud service operated by the tool.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: https://security.google.com/settings/security/permissions. When access is revoked, the local token stops working and the locally stored analytics files are deleted within 7 days. Deletion can also be requested by email (below) and is completed within 7 days.

Children

The tool is not directed at children and collects no data from children.

Changes

Any change to this policy will be posted on this page with a new effective date.
